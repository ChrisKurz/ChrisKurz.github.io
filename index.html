Byte-level visualization of Intel HEX files. Each pixel is one byte. Regions without data are highlighted. MCUboot image headers are detected, highlighted and interpreted.

Programmer →

Programmer is a local desktop web tool for detecting and programming Nordic nRF54L development boards via nRF Util and SEGGER J-Link, with support for firmware flashing, verification, erase, recover, and reset. It provides a simple graphical interface for selecting the target device and HEX firmware instead of working directly with the command line.

Serial AT Terminal →

This web-based serial terminal connects to serial devices in Chrome or Edge and supports sending and monitoring AT commands. Custom AT command sets can be edited, saved, and loaded for later use.

BLE Explorer →

BLE Explorer is a browser-based tool for discovering, connecting to, and debugging Bluetooth Low Energy devices. It uses the computer’s built-in Bluetooth interface, so no external Bluetooth dongle or development kit is required. It enables users to inspect GATT services and characteristics and perform read and write operations directly from the browser.
